# Expectation Decider — Probability & Statistics Project

## Project Objective

This project analyzes how **study hours**, **attendance**, and **group discussion participation** affect a student’s probability of **passing the final exam** using real dataset records of 200 students.
The project applies core concepts of **Probability and Statistics** to real academic behavior.

## Dataset

File used:

```
expectation_decider_dataset.csv
```

Dataset fields:

| Column              | Description                          |
| ------------------- | ------------------------------------ |
| study_hours         | Hours studied per week               |
| attendance          | Attendance percentage                |
| group_discussion    | Participation in discussion (Yes/No) |
| previous_test_score | Previous test marks                  |
| final_exam_pass     | Final exam result (Pass/Fail)        |

## Key Insights

* Overall pass rate: **41.5%**
* Pass rate among students in group discussions: **66.7%**
* High attendance increases pass probability to **80%** (Bayes result)
* Study hours alone do not guarantee success
* Group discussion is the **most influential factor**
* Events “discussion” and “passing” are **dependent**

---

## Conclusion

The project proves that:

> **Interactive learning and attendance** influence academic success more than only long study hours.

It demonstrates how **probability and statistics** can be applied to analyze real student performance.
